# 智策通 V1.0 范围说明

## 1. 文档目的

本文档用于冻结《智策通 V1.0 细分开发任务清单》中 M0.1 的演示范围，作为后续 M1-M8 的统一边界依据。

## 2. V1.0 总体范围

### 2.1 场景范围

- V1.0 只做高校政策服务场景
- 高校样板确定为西安电子科技大学
- 产品定位为可运行、可演示、可解释、可追溯的高校政策智能助手 Demo

### 2.2 首批事项

首批核心事项固定为：

1. 奖学金
2. 转专业
3. 毕业要求

### 2.3 辅助事项

辅助事项纳入知识库预留范围，但不作为首轮稳定演示主链路：

- 助学金
- 保研
- 请假
- 处分
- 学籍管理

### 2.4 第一版用户

V1.0 第一版用户固定为：

1. 学生
2. 管理员

说明：

- 学生端负责政策问答、资格判断、材料清单、流程生成
- 管理端负责政策文件上传、解析状态查看、知识库维护
- 辅导员、教务老师暂不做独立权限体系，只作为后续扩展角色

## 3. 演示闭环

V1.0 必须围绕以下闭环完成：

```text
管理员上传政策文件
-> 系统解析文件并构建知识库
-> 学生提出政策问题
-> 系统检索政策依据
-> 系统追问缺失条件
-> 输出资格判断
-> 输出材料清单与办理流程
-> 展示出处与风险提示
```

## 4. 必须完成的功能

### 4.1 学生端

- 自然语言政策问答
- 回答附带政策出处
- 资格判断
- 主动追问缺失条件
- 材料清单生成
- 办理流程生成
- 风险提示

### 4.2 管理端

- 政策文件上传
- 文件 metadata 录入
- 文件解析状态查看
- 已上传文件列表查看

### 4.3 技术能力

- 文本型 PDF / Word 解析
- 政策切片与 metadata 注入
- RAG 检索
- 轻量 Agent 编排
- 基础记忆能力
- 回答可追溯

## 5. 暂缓功能

以下能力明确不纳入 V1.0 首轮交付：

- 自动爬取学校官网与公告站点
- 扫描件 OCR
- 复杂表格结构化解析
- 多角色复杂权限体系
- 城市青年、企业、政务服务多域扩展
- 政策自动对比与更新提醒
- LangGraph 等重型 Agent 编排框架
- Redis、长期记忆检索等增强能力

## 6. 路演稳定案例

V1.0 路演优先展示以下三条主链路：

1. 奖学金政策问答
2. 转专业资格判断
3. 毕业要求问答

其中最稳定、最适合主讲的两条链路为：

1. 挂科后能否申请奖学金
2. 绩点 3.4 是否可以申请转专业

## 7. 验收映射

对应 M0.1 验收标准，本文档已明确：

- 已形成 V1.0 范围说明
- 已区分必须完成功能与暂缓功能
