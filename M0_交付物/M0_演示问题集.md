# M0 演示问题集

## 1. 文档目的

本文档用于完成 M0.3 演示问题集准备任务，为后续 RAG 测试、问答页面联调和路演脚本提供统一问题池。

## 2. 路演稳定案例

以下 3 个问题标记为路演稳定案例：

1. `【稳定案例 1】` 我挂过一门课，还能申请奖学金吗？
2. `【稳定案例 2】` 我大一绩点 3.4，想转计算机专业，可以吗？
3. `【稳定案例 3】` 我学分不够会影响毕业吗？

推荐路演顺序：

1. 管理员上传政策文件
2. 演示稳定案例 1，突出政策检索、引用、风险提示
3. 演示稳定案例 2，突出主动追问、资格判断、流程生成
4. 演示稳定案例 3，突出毕业要求类问答能力

## 3. 问题池

### 3.1 奖学金类

1. `【稳定案例 1】` 我挂过一门课，还能申请奖学金吗？
2. 奖学金申请需要满足什么条件？
3. 奖学金评定更看成绩还是综合表现？
4. 如果我有违纪记录，还能参加奖学金评定吗？

### 3.2 转专业类

5. `【稳定案例 2】` 我大一绩点 3.4，想转计算机专业，可以吗？
6. 转专业需要准备哪些材料？
7. 转专业申请时间一般在什么时候？
8. 如果我有补考记录，还能申请转专业吗？

### 3.3 毕业要求类

9. `【稳定案例 3】` 我学分不够会影响毕业吗？
10. 毕业设计没有按时提交会有什么影响？
11. 本科毕业论文有哪些基本规范要求？
12. 如果毕业审核时材料不完整，应该先补什么？

## 4. 建议回答结构

每个问题的系统回答建议统一为：

1. 简要结论
2. 通俗解释
3. 政策依据
4. 资格判断或限制条件
5. 风险提示
6. 下一步建议
