# M0 演示问题集

## 1. 文档目的

本文档用于完成 M0.3 演示问题集准备任务，为后续 RAG 测试、问答页面联调和路演脚本提供统一问题池。

## 2. 路演稳定案例

以下 8 个问题标记为路演稳定案例：

1. `【稳定案例 1】` 我挂过一门课，还能申请奖学金吗？
2. `【稳定案例 2】` 家庭经济困难认定后怎么申请国家助学金？
3. `【稳定案例 3】` 我大一绩点 3.4，想转计算机专业，可以吗？
4. `【稳定案例 4】` 我有一次挂科还能保研吗？
5. `【稳定案例 5】` 我学分不够会影响毕业吗？
6. `【稳定案例 6】` 因病休学需要什么证明？
7. `【稳定案例 7】` 受到处分会影响保研吗？
8. `【稳定案例 8】` 学籍信息变更需要哪些材料？

推荐路演顺序：

1. 管理员上传政策文件
2. 演示稳定案例 1，突出奖学金政策检索、引用、风险提示
3. 演示稳定案例 3，突出转专业主动追问、资格判断、流程生成
4. 演示稳定案例 4 或 7，突出高影响事项人工复核提示
5. 演示稳定案例 5，突出毕业要求类问答能力

## 3. 问题池

### 3.1 奖学金类

1. `【稳定案例 1】` 我挂过一门课，还能申请奖学金吗？
2. 奖学金申请需要满足什么条件？
3. 奖学金评定更看成绩还是综合表现？
4. 如果我有违纪记录，还能参加奖学金评定吗？

### 3.2 转专业类

5. `【稳定案例 2】` 我大一绩点 3.4，想转计算机专业，可以吗？
6. 转专业需要准备哪些材料？
7. 转专业申请时间一般在什么时候？
8. 如果我有补考记录，还能申请转专业吗？

### 3.3 助学金类

9. `【稳定案例 2】` 家庭经济困难认定后怎么申请国家助学金？
10. 国家助学金平均资助标准是多少？
11. 助学贷款和绿色通道有什么区别？
12. 临时困难补助适合什么情况？

### 3.4 保研类

13. `【稳定案例 4】` 我有一次挂科还能保研吗？
14. 推免资格主要看哪些条件？
15. 有处分记录会不会影响推免？
16. 科研竞赛材料在推免中怎么核查？

### 3.5 毕业要求类

17. `【稳定案例 5】` 我学分不够会影响毕业吗？
18. 毕业设计没有按时提交会有什么影响？
19. 本科毕业论文有哪些基本规范要求？
20. 四级没过会不会影响学位？

### 3.6 请假类

21. `【稳定案例 6】` 因病休学需要什么证明？
22. 新生不能按时报到请假多久以内有效？
23. 休学最短和最长可以多久？
24. 复学需要提前什么时候申请？

### 3.7 处分类

25. `【稳定案例 7】` 受到处分会影响保研吗？
26. 处分决定出来后还能申诉吗？
27. 纪律处分有哪些种类？
28. 考试违纪会受到什么处理？

### 3.8 学籍管理类

29. `【稳定案例 8】` 学籍信息变更需要哪些材料？
30. 累计未通过学分会导致降级吗？
31. 退学处理一般有哪些情形？
32. 学籍档案中的姓名、身份证号能修改吗？

## 4. 建议回答结构

每个问题的系统回答建议统一为：

1. 简要结论
2. 通俗解释
3. 政策依据
4. 资格判断或限制条件
5. 风险提示
6. 下一步建议
