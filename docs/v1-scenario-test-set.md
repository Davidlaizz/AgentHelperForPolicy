## 2. 分场景问题池

### 奖学金

1. 我挂过一门课，还能申请奖学金吗？
2. 奖学金申请需要满足什么条件？
3. 有纪律处分还能参加奖学金评定吗？
4. 综合测评排名和学习成绩排名哪个更关键？
5. 毕业生奖学金和综合发展奖学金有什么区别？

### 助学金

1. 家庭经济困难认定后怎么申请国家助学金？
2. 国家助学金平均资助标准是多少？
3. 退役士兵学生能不能享受国家助学金？
4. 助学贷款和绿色通道有什么区别？
5. 临时困难补助适合什么情况？

### 转专业

1. 我大一绩点 3.4，想转计算机专业，可以吗？
2. 大类专业分流系统在哪里进入？
3. 转专业需要准备哪些材料？
4. 有挂科或补考记录还能申请转专业吗？
5. 大类分流对象包括哪些学生？

### 保研

1. 我有一次挂科还能保研吗？
2. 推免资格主要看哪些条件？
3. 推免中科研竞赛材料怎么核查？
4. 有处分记录会不会影响推免？
5. 学院推荐和学校审核分别做什么？

### 毕业

1. 我学分不够会影响毕业吗？
2. 四级没过会不会影响学位？
3. 结业后还能换发毕业证吗？
4. 校外做毕业论文需要什么申请表？
5. 毕业论文盲审不通过怎么办？

### 请假

1. 因病休学需要什么证明？
2. 新生不能按时报到请假多久以内有效？
3. 休学最短和最长可以多久？
4. 复学需要提前什么时候申请？
5. 休学期间发生违纪会影响复学吗？

### 处分

1. 受到处分会影响保研吗？
2. 处分决定出来后还能申诉吗？
3. 纪律处分有哪些种类？
4. 考试违纪会受到什么处理？
5. 处分对奖学金和毕业有哪些风险？

### 学籍管理

1. 学籍信息变更需要哪些材料？
2. 累计未通过学分会导致降级吗？
3. 退学处理一般有哪些情形？
4. 学籍档案中的姓名、身份证号能修改吗？
5. 休学、保留学籍和复学材料由哪里保存？

## 3. 验收方式

1. 前端 `/cases` 能展示 8 类事项。
2. 前端 `/eligibility` 能按 8 类切换示例并触发 Agent 追问。
3. 前端 `/policies` 按类别可看到对应政策文件。
4. 后端 `/api/chat` 对每类至少 1 个问题返回政策依据和引用出处。
5. 高风险事项，如保研、处分、毕业，应给出人工复核风险提示。
