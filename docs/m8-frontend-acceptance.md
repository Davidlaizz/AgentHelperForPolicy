# M8 前端页面细化与验收说明

## 1. 当前状态

M8 已完成 V1.0 Demo 前端打磨与验收闭环。

重点变化：

- 首页从单纯入口页升级为政策服务工作台
- 智能问答页增加会话脉络、演示脚本和风险提示展示
- 智能问答与资格判断页支持轻量 Markdown 渲染，适配模型输出中的加粗、列表和标题
- 资格判断页从占位页升级为可运行的 Agent 判断页
- 事项中心页从占位页升级为 8 类事项卡片、FAQ、材料、流程和风险提醒入口
- 管理后台与政策库沿用 M7 的后台治理能力
- 全局导航增加当前页高亮和移动端可横向滚动
- 全局色板从单一灰阶调整为更清晰的蓝绿业务色板

## 2. 页面验收

### `/`

首页模块：

- 政策服务工作台首屏
- 稳定演示问题
- 快捷入口
- 快捷事项
- Demo 闭环流程

验收结果：

- 首屏能说明产品价值
- 不只是一个聊天框
- 评委能看到“上传政策 → 检索问答 → Agent 判断 → 后台治理”的完整路径

### `/chat`

问答页模块：

- 会话脉络
- 演示脚本
- 消息区
- 输入框
- 政策依据
- AI 推断
- Markdown 格式化回答
- Agent 状态
- 风险提示
- 引用出处

验收结果：

- 支持 URL 预填问题：`/chat?question=...`
- 可完成政策问答主流程
- 回答包含出处和风险提示
- 回答中的 `**加粗**`、编号列表和小标题会渲染为结构化文本

### `/eligibility`

资格判断页模块：

- 当前事项
- 已知条件
- 待补充条件
- Agent 追问区
- 判断结果
- 政策依据
- Markdown 格式化政策依据
- 材料线索
- 办理流程
- 八类事项示例切换

验收结果：

- 可以展示“我是否符合条件”的完整过程
- 支持多轮追问和条件补齐演示
- 支持奖学金、助学金、转专业、保研、毕业、请假、处分、学籍管理场景切换

### `/cases`

事项中心模块：

- 事项分类
- 覆盖状态
- 常见问题
- 材料线索
- 办理步骤
- 风险提醒
- 开始咨询
- 进入资格判断

验收结果：

- 用户可以按事项进入，而不是只能从聊天框开始
- 首页 8 类快捷事项与事项中心 8 类详情保持一致

### `/admin` 与 `/policies`

沿用 M7 能力：

- 文件上传
- 文件管理
- 条款查看
- 热门问题
- 标准答案
- 数据看板

验收结果：

- 能体现系统可运营、可落地

## 3. 浏览器验收

已使用浏览器验证：

```text
http://127.0.0.1:3000/
http://127.0.0.1:3000/cases
http://127.0.0.1:3000/eligibility
http://127.0.0.1:3000/chat?question=校外做毕业论文需要什么申请表？
```

检查结果：

- 首页包含“智能工作台”“Demo 闭环”“快捷事项”
- 事项中心包含“转专业 / 大类分流”和“开始咨询”
- 资格判断包含“当前事项”和“Agent 追问区”
- 问答页能自动提交 URL 中的问题并展示回答
