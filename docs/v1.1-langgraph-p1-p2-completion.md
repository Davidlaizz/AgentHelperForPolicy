# 智策通 V1.1 P1/P2 完成记录

日期：2026-05-24

## 1. P1 Agent 智能化增强

本轮已完成 P1 第一版：

1. `IntentAgent` 引入 LangChain `PydanticOutputParser`，优先使用 structured output 输出 `intent`、`confidence`、`reason`。
2. `SlotAgent` 引入 LangChain `PydanticOutputParser`，优先按当前事项允许的 slot key 输出 `extracted_slots`、`confidence`、`reason`。
3. structured output 调用失败或输出置信度不足时，自动回退到现有规则识别，保证演示链路稳定。
4. `SlotAgent` 会对结构化输出做字段白名单过滤和类型归一，包括数字、布尔值和字符串。
5. Agent 节点执行 wrapper 增加输出字段校验，节点缺少关键输出时会被记录为失败，避免错误状态静默流转。
6. `AnswerAgent` prompt 已强化“政策依据”和“AI 推断”的边界，要求不确定点进入 AI 推断。

## 2. P2 后台可视化与治理能力

本轮已完成 P2 第一版：

1. 管理后台新增多 Agent 状态图，按 LangGraph 编排顺序展示节点和路由。
2. 状态图会根据最近选中的运行记录标记已执行节点和失败节点。
3. Agent 节点卡片展示调用次数、平均耗时、失败次数、启停状态、输入字段、输出字段和最近失败信息。
4. 新增节点治理统计表，集中展示节点类型、调用量、平均耗时、失败次数、输入字段和输出字段。
5. 最近运行记录可查看运行详情，运行详情中展示问题、意图、事项、风险、总耗时和每一步输入/输出摘要。
6. 后端 `/api/management/agent-graph` 和 `/api/management/agent-nodes` 已返回 `call_count`、`last_failure_message`、`last_failure_at` 等治理字段。

## 2.1 P2.1/P2.2 编排图增强

已继续完成 P2.1 和 P2.2：

1. 将原卡片网格升级为单张 SVG Agent 编排图，在同一画布中展示节点、边、方向和条件。
2. 每个节点展示类型、最近运行是否命中、入参数量、出参数量和平均耗时。
3. 每条边以箭头连接源节点和目标节点，并将 `always`、`missing_slots`、`eligibility_check`、`workflow_or_material`、`policy_qa_or_general` 翻译为中文业务含义贴在边上。
4. 节点支持点击，右侧详情展示职责、入参、出参、调用次数、平均耗时、失败次数和最近运行输入/输出摘要。
5. 边支持点击，右侧详情展示源节点、目标节点、条件、条件表达式和业务解释。
6. 该实现未引入 React Flow，采用轻量前端组件实现，优先保证当前比赛 Demo 稳定。
