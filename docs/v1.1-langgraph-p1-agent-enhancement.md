# 智策通 V1.1 P1 Agent 智能化增强记录

日期：2026-05-24

## 1. 本次推进范围

本次围绕 P1 的“证据分层增强”和“风险提示增强”先完成第一版低风险实现，目标是让多 Agent 不只完成问答流程，还能把政策依据按层级、有效期和附件来源结构化出来，并把这些结构化结果反馈给风险校验和前端展示。

## 2. 后端增强

### 2.1 EvidenceAgent 证据分层

`EvidenceAgent` 已从简单统计升级为分层证据摘要，新增字段包括：

| 字段 | 含义 |
| --- | --- |
| `school_level_titles` | 命中的学校通用政策 |
| `college_level_titles` | 命中的学院细则 |
| `annual_notice_titles` | 命中的年度通知或临时通知 |
| `attachment_titles` | 命中的附件材料 |
| `missing_effective_date_titles` | 缺少明确生效/失效时间的政策 |
| `expired_titles` | 根据当前日期判断已过期的政策 |
| `attachment_only` | 当前证据是否主要来自附件材料 |
| `policy_levels` | 政策层级数量分布 |

同时修正了原先“只要存在 `effective_to` 就视为可能过期”的粗粒度判断，现在只在 `effective_to < 当前日期` 时进入过期候选。

### 2.2 RiskAgent 风险提示

`RiskAgent` 在复用原有 `build_risk` 的基础上，新增基于 `evidence_summary` 的提示：

1. 政策缺少明确有效期时，提示人工复核时效性。
2. 命中已过期政策时，提示可能存在版本风险。
3. 同时命中学校政策和学院细则时，提示需要按学院、年级和具体通知核对。
4. 证据主要来自附件时，提示应结合政策正文确认条件。

风险等级仍保持保守策略：默认不轻易升到 `high`，证据边界不清时升到 `medium`。

### 2.3 Agent 响应结构

`AgentResponse` 已新增 `evidence_summary` 字段，前端和后台可以直接使用同一份结构化证据摘要。

## 3. 前端展示

问答页 `AgentPanel` 已新增“证据分层”折叠区域，支持展示：

1. 检索证据段数量。
2. 政策层级分布。
3. 校级政策、学院细则、年度通知、附件材料。
4. 缺少有效期和可能过期的政策标题。

这让路演时可以直接说明：系统不仅检索到了片段，还能判断这些片段属于哪一类政策依据、是否存在时效风险、是否需要结合附件或学院口径。
